IPHONE REFRESH

用 iPhone
更新直播

iPhone 只負責短暫取得官方網址，不是伺服器；更新後關閉 App 也能繼續用途播。

安裝 Scriptable

SETUP

第一次設定

安裝免費的 Scriptable，按上方「複製更新程式」，在 Scriptable 新增一個 Script 並貼上，名稱可填「更新新聞直播」。執行後輸入 Cloud Run 管理頁使用的 ACCESS_KEY。

之後若途播無法開台，只要先執行這個 Script；成功訊息出現後回到途播即可。權杖只保存在 iPhone Keychain，不會寫進程式碼。
