使用方式

  1. 在上方輸入本服務專用的播放權杖。
  2. 按「複製 M3U 網址」，到途播新增遠端 M3U 清單。
  3. 第一次點某個頻道時，Relay 會向官方行動直播服務取得當下的 HLS，通常只需幾秒。

行車安全：請只在安全停車時操作與觀看影像；行駛中應以音訊為主並遵守當地法規。

本服務不保存影片、不破解 DRM，也不加入付費或私人來源。影像資料會從官方公開來源經 Cloud Run 轉送，因此可能產生 Google Cloud 對外流量費用。
